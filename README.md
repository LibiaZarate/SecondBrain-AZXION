# Segundo Cerebro

**Cómo construir tu propio sistema operativo con IA.**

> Este es el método con el que opero mi negocio todos los días. No es teoría:
> es lo que quedó después de romperlo varias veces en producción, con clientes reales
> y dinero real de por medio.
>
> Lo comparto como está. Si te sirve, perfecto. Si no, también.

---

## La tesis, en una línea

**Tu segundo cerebro no es donde guardas cosas. Es donde se toman decisiones.**

Casi todo lo que vas a encontrar allá afuera con el nombre "second brain" es una bóveda
de notas: carpetas bonitas, etiquetas, enlaces entre notas. Eso es un archivero. Sirve
para *recordar*, no para *operar*.

La diferencia es una sola pieza: **un runtime**. Un agente que lee esos archivos y los
ejecuta. Sin runtime tienes documentos. Con runtime tienes un sistema.

```
archivos  =  el manual
agente    =  el runtime
sistema   =  los dos juntos
```

El manual es el producto. La IA solo lo corre.

## Qué NO es

- **No es una app.** No hay nada que instalar más allá de un agente de código y una carpeta.
- **No es una plantilla de Notion ni de Obsidian.** Puedes usarlos, pero no son el sistema.
- **No es productividad personal.** No hay hábitos, ni rachas, ni gamificación.
- **No es una herramienta que te acompaña.** Es una que trabaja mientras no estás.

## Para quién NO es

- Para quien quiera organizarse mejor sin cambiar nada de cómo decide. Esto no ordena: obliga a definir.
- Para quien busque un sistema terminado. Lo que hay aquí es un esqueleto; **la lógica de tu trabajo la tienes que escribir tú.** Es la única parte difícil y no la puede hacer nadie más.
- Para quien no quiera escribir. Este método es 80% escribir lo que ya sabes hacer y 20% conectarlo.

## De dónde sale

Lo construí para mí, no para publicarlo. Corre un negocio de infraestructura con IA:
varios clientes en producción, sistemas que atienden gente real, y una carrera de
ingeniería encima. Ese fue el filtro más honesto que pudo tener: **todo lo que pedía
mantenimiento se murió solo.** Lo que sobrevivió es lo que está aquí.

Por eso el método tiene tan pocas piezas. No es minimalismo estético, es selección natural.
